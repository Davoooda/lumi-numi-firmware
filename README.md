# Lumi-Numi firmware releases

Binary firmware for Lumi-Numi devices, published as GitHub Releases for over-the-air updates.
No source code here — only `.bin` assets.

- `roboface-s3-v<version>.bin` — Lumi-Numi 2 (Waveshare ESP32-S3-Touch-LCD-1.83), release tags `s3-v<version>`
- `lumi-numi-<board>-v<version>.bin` — Lumi-Numi universal builds, tags `v<version>`

The device checks this repo's releases when you press **Settings → Update**.
